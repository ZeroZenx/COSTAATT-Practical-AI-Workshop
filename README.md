# COSTAATT Practical AI Workshop

Interactive one-day professional development workshop for managers, supervisors, administrative professionals, entrepreneurs and public officers.

Live site: https://costaattworkshop.site

## What is included

- Eight applied workshop sessions
- Participant workbook saved as a styled PDF through the browser print flow
- Completion certificate after all eight sessions finish
- Facilitator desk with presentation mode and activity controls
- Consent-gated participant progress reporting
- Responsible AI checklist and take-home prompt toolkit
- COSTAATT branding and Technology Services Department attribution

## Run locally

```sh
npm install
npm run dev
```

Open http://127.0.0.1:4173.

## Validate the build

```sh
npm run check
```

The public version uses a Cloudflare Worker and D1 for opted-in progress reporting. Participant notes, prompts and activity answers stay in the participant browser.
